# Security Policy

## Supported Versions

twinelink is pre-1.0. Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/marcelofrau/twinelink-desktop/security/advisories/new).

Do not open a public issue for security reports.

Include, when possible:

- Affected component (daemon, indicator, UI, plugin)
- Steps to reproduce
- Impact assessment (remote code execution, information disclosure, etc.)

You will receive an acknowledgement within 7 days. Confirmed vulnerabilities
are fixed before public disclosure and credited in the advisory unless you
prefer to remain anonymous.

twinelink inherits attack surface from KDE Connect (network protocol, plugin
system, certificate handling). Reports against upstream-shared code are
welcome here; we will coordinate disclosure where relevant.
